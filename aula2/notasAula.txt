CSS - Cascading Style Sheets

sintaxe

selector    declaration     declaration
h1          {color: blue;   font-size:  12px}
            propery:value   propery     value

seletores

Elemento
p{ <!--Paragrafo-->
    text-align: center;
    color: red;
}


class
    comeca com ponto
.p{
    text-align: center;
    color: blue;
}

Id
    unico
#p {
    text-align: center;
    color: green;
}

Universal
    aplica em toda pagina html
*{
    text-align: center;
    color: blue;
}

Interno
 - dentro do arquivi html em Style, colocado no head

Externo
 - arquivo somente para o css chamado dentro do html no head

    <head>
    <link rel="stylesheet" href="mystyle.css">
    </head>

Inline
 - inserido diretamente na tag
    <h1 style="color:blue;text-align:center;">Título</h1>
    <p style="color:red;">Parágrafo .< /p>

Margin

    border: 1px solid black;

    background-color: lightblue;
    }
</ style>

    <style>
        div {

        }

Float
Left - O elemento flutua à esquerda de seu container
right - O elemento flutua à direita de seu container
none - o elemeto não flutua (será exibido exatamente onde ocorre no texto). é padão
inherit - o elemento herda o valor Float de seu pai
<style>
img {
    float: right;
}
</style>
